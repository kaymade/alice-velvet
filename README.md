# Alice Velvet

Alice Velvet is a dark and light Obsidian theme inspired by a whimsical storybook tea table, velvet shadows, playing-card reds, and an Alice-in-Wonderland palette. The dark mode uses deep Onyx backgrounds, muted Wineshade panels, pale Gin Tonic text, and dramatic Claret and Red Suits accents, while the light mode softens the palette into an aged-paper workspace with Onyx text and Claret details.

The theme is designed for a moody, literary workspace with soft contrast, decorative headings, rounded interface details, and restrained pink highlights. It works best with the following fonts installed locally:

- Cormorant Garamond for note titles
- Yeseva One for headings
- Nunito for body text and interface text
- Emilys Candy for small accent elements such as tags and root folder labels

## Modes

Alice Velvet supports both dark and light mode. The dark mode keeps the original moody velvet look, while the light mode is designed as a softer companion for daytime writing.

## Installation

### Obsidian Community Themes

Alice Velvet is available through Obsidian's official Community Themes directory:

1. Open **Settings > Appearance**
2. Next to **Themes**, select **Manage**
3. Search for **Alice Velvet**
4. Select **Install and use**

### Manual Installation

1. Download `theme.css` and `manifest.json`.
2. Create an `Alice Velvet` folder inside your vault's `.obsidian/themes/` directory.
3. Place both files inside the folder.
4. Restart Obsidian and select **Alice Velvet** under **Settings > Appearance**.

## Features

- Coordinated dark and light modes
- Custom typography across headings, note titles, interface text, and accents
- Custom color system built around the Alice Velvet palette
- Styled navigation, tags, folders, and workspace elements
- Rounded interface details and restrained accent treatments
- Designed for both writing-focused and general knowledge-management workflows

## Technical Design

Alice Velvet is a standalone CSS theme built on top of Obsidian's existing interface and design variables. Its color and typography systems coordinate the editor, navigation, workspace surfaces, and interface elements across separate dark and light modes.

The theme uses CSS custom properties and targeted interface styling to maintain a consistent visual system without requiring companion plugins.
